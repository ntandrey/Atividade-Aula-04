Nessa atividade da faculdade, desenvolvi um Livro de Receitas Rápidas usando 100% HTML. O foco era criar toda a estrutura do zero para colocar em prática os conhecimentos aprendidos em aula. Nessa atividade foi usado formulários, vídeos, imagens, tabelas, etc.. Esse site possui várias receitas de várias categorias, como: doces, salgados, bebidas. O objetivo é facilitar e ensinar o preparo de alimentos de forma simples e rápida.
